# Caca Utils

Caca Utils is a collection of useful
cross-platform bash scripts using
[libcaca](
  http://caca.zoy.org/wiki/libcaca)
and written using the
[Crash Bash](
  https://github.com/themartiancompany/crash-bash)
library.

```bash
  cacawrite
    <in-file>
    <out-file>
```

On Android it relies on the
[sdotool](
  https://github.com/themartiancompany/sdotool)
input automation program in order
to hide the software keyboard while
saving the pictures.

This program is a dependency for
[Media Tools](
  https://github.com/themartiancompany/media-tools)
and
[Picture Viewer](
  https://github.com/themartiancompany/picture-viewer),
and as a consequence, of the undeletable, decentralized
Twitter.

Being the undeletable Twitter a core component of
[DogeOS](
  https://github.com/themartiancompany/dogeos),
this program is too.

## Installation

The tools in this source repo
can be installed from source using GNU Make.

```bash
make \
  install
```

The collection has officially published on the
the uncensorable
[Ur](
  https://github.com/themartiancompany/ur)
user repository and application store as
`caca-utils`.
The source code is published on the
[Ethereum Virtual Machine File System](
  https://github.com/themartiancompany/evmfs)
so it can't possibly be taken down.

To install it from there just type

```bash
ur \
  caca-utils
```

A censorable HTTP Github mirror of the recipe published there,
containing a full list of the software dependencies needed to run the
tools is hosted on
[caca-utils-ur](
  https://github.com/themartiancompany/caca-utils-ur).

Be aware the mirror could go offline any time as Github and more
in general all HTTP resources are inherently unstable and censorable.
